# MobiMark v0.3.1 — 首次 GitHub 發布 / First GitHub publication

## 繁體中文

MobiMark（原 Ahuimark）Android 續航工具首次於此倉庫發布。v0.3.1 放大圖示本體，並公開目前原始碼、繁體中文／英文說明、測試規範、實際軟體畫面及素材署名。

- 五項負載：Godot 3D、網頁、影片、後鏡頭 4K30、文書；每項 3 分鐘，一輪 15 分鐘。
- 完整 80%→20%、快速 4 小時與當機紀錄推算，統一提供等效 100% 續航並區分測量方式。
- 線上／離線網頁、1–3 個自訂網址；線上／本地影片；DOCX／XLSX／PPTX 及動態圖表。
- 已測試時間、快速倒數、橫向緊湊資訊列、多組成績歷史、分項耗電及報告匯出。
- 定時備援、勿擾、音量管理、白畫面亮度校正與測試結束後解除防休眠。

**下載：**一般使用者只需 `MobiMark-v0.3.1-debug.apk`。`prism_front.pck` 是提供開發者的同版本遊戲封包，放至 `app/src/main/assets/` 可建置；`SHA256SUMS.txt` 核對兩個附件。MP4 不包含在 Release。

**限制：**此為預覽用途的 debug APK，非正式商店簽章。Android 最低 API 26，仍須符合 GPU／4K30 相機等要求。既有建置成功、73 項單元測試通過、Lint 0 errors / 18 warnings，不等於完整續航或所有實機相容性已驗證。線上影片／相機／GPU 需於目標機實測。成績是外推值，不保證真實 100%→0% 時間。

## English

First publication of MobiMark (formerly Ahuimark) in this GitHub repository. v0.3.1 enlarges the app icon artwork; this publication includes source, Chinese-default and English documentation, protocols, real software captures and asset credits.

- Five 3-minute workloads / 15-minute cycle: Godot 3D, web, video, rear 4K30 recording and office.
- Full 80%→20%, four-hour quick mode and crash-record estimates; equivalent 100% runtime with measurement types distinguished.
- Online/offline web, 1–3 custom URLs, online/local video, actual DOCX/XLSX/PPTX and animated charts.
- Elapsed/remaining timers, compact landscape UI, multi-result history, per-stage consumption and report export.
- Checkpoints, DND, volume management, white calibration screen and wake-lock release after testing.

**Download:** end users need only `MobiMark-v0.3.1-debug.apk`. Developers may place the matching `prism_front.pck` in `app/src/main/assets/` to build. `SHA256SUMS.txt` verifies both assets. No test MP4 is redistributed.

**Limitations:** preview debug APK, not production/store signing. Minimum API 26 does not guarantee GPU/4K30 camera compatibility. Existing builds passed, 73 unit tests passed, lint has 0 errors / 18 warnings; this is not full-endurance or all-device validation. Verify video/camera/GPU on target hardware. Extrapolated scores do not guarantee actual 100%→0% runtime.
